How to Design Motifs

  • Sector Tile: Edit the active motif on the left. The vertical axis represents radius from hub (r = 0.0) to outer rim (r = 1.0).
  • Explicit Tiers: Adjust R Start and R End to lock endpoints to concentric circles.
  • Stepped Finials: Set R End of a lower branch to match R Start of an upper branch for seamless connectivity.
  • Phase Clocking: Use the Phase slider to interlace motifs around the medallion without breaking symmetry.
